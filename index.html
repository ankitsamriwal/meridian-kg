Ask the graph anything about the engagement.

Every answer is assembled from a real graph traversal and shows its path and sources. Switch roles to see query-time access control change what the graph will say.

  • Every dot is one thing found in the documents - a person, system, project, risk, requirement. The color is its type (legend, bottom left).
  • Dot size = connections. The bigger the dot, the more relationships it has. Big dots are the hubs everything else revolves around.
  • Every line is one relationship the documents state - who designed what, what depends on what, who owns which risk.
  • Line thickness = confidence between 0 and 1 - how sure the read was. Thin, faint lines are worth double-checking against their source.
  • Moving dots on a line mean the AI read that relationship out of written text. A still line was mapped directly from structured data.
  • Tap any dot for everything it connects to, with the source document behind each link.

Entity resolution log

When the same thing shows up under two names - in the demo, "A. Samriwal" in a status note and "Ankit Samriwal" in the roster - Meridian keeps one, so the graph stays connected instead of splitting into lookalikes. Each row: duplicate name → the name kept, and how the match was decided (rule = exact logic, embedding = names that mean the same, score = match strength, 0 to 1).

Design principles honored

  • Structured sources mapped directly. D365 entities, roster and the repo dependency graph go in deterministically - no LLM. Only docs, emails and notes go through extraction.
  • Entity resolution is not optional. Rule-based + embedding-similarity merges run as a stage; every merge is logged above.
  • Provenance and permissions travel with the data. Every node, edge and chunk carries its source document and the roles from its source system, enforced at query time via the role switcher.
  • Hybrid retrieval. Vector search finds related chunks; graph traversal answers how things connect and via which path. The LLM only synthesizes from what retrieval returned.
